## 1. 位置づけ

`メディア戦略.md` 4章で「CVへの主力は将来的にSNS、SEOは並行するチャネルの一つ」と決めてある。その **SNS側の具体化がこのファイル**。

- **ゴールはPVでもフォロワーでもなく、公式LINEの友だち追加と無料相談**（LPと同じCV定義）
- SEOが「検索した人を拾う」のに対し、SNSは**まだ言語化していない層に「こういうやり方がある」と気付かせる**役割。記念日代行・プレゼント選び代行は**認知の薄いカテゴリ**なので、検索だけでは母数が足りない
- 運営は1人・本業の合間。**週3投稿が上限**という前提で全部を設計する。回らない計画は書かない

### 時間軸（重要）

いま 2026-08-27。**Week 0 は 8/31 の週から**。

**★着火は11月上旬（11/2 の週）。** 記念日商材の検討は本番の2〜4週間前に始まるが、**クリスマスのレストランは11月上旬には埋まり始める**ので、「もう動かないと取れない」という訴求はそこに置く必要がある（当初「11月中旬着火」としていたのを、実日付を当てて前倒しした。11月中旬だと軸2が丸ごと間に合わない）。

**12/24 は起点から118日先＝90日の外。** つまり **90日は助走で、本番はその後の5週間**（11/16〜12/24）。90日でやるのは「型が固まって、過去投稿から人柄と提案力が伝わる状態」を作るところまで。ゼロから始めて12月に間に合わせるのは無理なので、**今から始めることそのものが戦略の中心**。

## 3. プラットフォームの役割分担

**主戦場はInstagram。Xは補助。TikTokは条件付きで開ける。広告は第2段。**

### 伸び方の違い（この分担の根拠）

**3つとも「伸びる」の定義が違う。** 同じ素材でも狙う行動が変わるので、同じ本文を並べて出す意味がない。
**1投稿1プラットフォームにする本当の理由はここ**（ツールの制約は2つ目の理由）。

| | Instagram | X | TikTok |
|---|---|---|---|
| 新規リーチの出どころ | **リール**（発見・おすすめ） | 初速の会話量とリポスト | **レコメンド一本** |
| いちばん重い行動 | **送信（DMでシェア）と保存** | 返信・引用＝会話量 | **完全視聴とループ** |
| 効きが落ちたもの | いいね中心の設計／ハッシュタグ頼み | **外部リンク**（リーチが落ちる） | 長い前置き |
| フォロワー0からの伸び | 出る（発見に乗ればフォロワー数と無関係） | 出にくい | **いちばん出る** |
| 勝負が決まる時間 | 24〜72時間。後からじわ伸びする | **30〜60分** | 数日〜数か月。**古い動画が跳ねる** |
| 掴みの単位 | 1枚目のサムネ／最初の3秒 | 1行目 | 1〜2秒＋音 |
| Annivの使い所 | **「これ送りたい」を作る** | コピーの高速A/B | リールの二次利用 |

**設計への落とし込み**

- **IGは「送りたくなるか」で作る。** 1枚目に条件だけ出して答えを伏せるのは、保存と送信の両方を取りにいく形
- **Xは「言い切りの1行」で作る。** 素材を作り込まず、コピーだけを変えて試す
- **TikTokはリールの流用でいい。** 冒頭のテキストフックだけ差し替える
- **流用は一方向に固定する**（Xで当たった言い回し → IG、IGで伸びたリール → TikTok）。制作の手戻りが消える

### Instagram（主戦場）

- ターゲット（恋人・交際中カップル、20〜30代）と利用者層が一致する
- 商材がビジュアル（プレゼント・ケーキ・バルーン・レストラン・演出の瞬間）で、**テキストより写真・動画のほうが伝達効率が高い**
- **API利用料が発生しない**。本数を増やしてもコストは制作工数だけ
- リール＝新規リーチ、カルーセル＝保存されて後から効く、ストーリーズ＝既存フォロワーへの接触とCV導線。**この3つで役割が違う**ので、どれか1つに寄せない
- **新規リーチの入口はリールだけ。** カルーセル・フィードはフォロワーと発見タブが中心なので、**週1本のリールを外さない**
- **いいねより「友達に送られたか」が重い。** 記念日商材はここが構造的に有利で、**「これやってほしい」がそのままDMシェアになる**。希望を伝える手段として使われる投稿を作る
- ハッシュタグの効きは落ちた。かわりに**キャプションのテキストが検索に効く**ので、狙う語をそのまま本文に書く
- **ストーリーズはリーチを増やさない。** 関係維持とCV導線に用途を限定する
- フォロワー数と無関係にリーチが出るので**立ち上げ期に最も有利**。逆に、保存も送信もされない投稿はフォロワーが増えても伸びない

### X（補助・低コストの実験場）

- **リンク無しの投稿は $0.015（約2.3円）**。訴求コピーを安く大量に試せる。ここで反応の良かった言い回しを**Instagramカルーセルの1枚目に転用する**のが本命の使い道
- **リンクを含む投稿は $0.20（約31円）＝13倍**。「Xで記事やLPへ送客する」設計はやればやるほど課金される構造なので**採らない**。リンクは**プロフィール欄と固定ポスト1本**に集約する
- 記念日・サプライズ商材の拡散力はIG/TikTokに劣る。**主力にしない**
- **外部リンク付きはリーチ自体も落ちる。** API課金13倍という金の話と結論が一致するので、リンクを貼らない判断に迷う余地がない
- 伸ばす王道は**他アカウントの会話にリプライで入る**こと。ただし**1人運営で回遊する工数が重い**
- ★**反応が30分〜1時間で出るのは他にない利点。** コピーのA/Bを1日単位で回せる。**これがXを持つ唯一の理由**
- テキストの検索性はIGより高いので、**指名検索（「Anniv」）の受け皿**としては効く

### TikTok（保留。開ける条件は10章）

- リーチの上限は最も高く、**IGリール用に作った縦動画をそのまま流用できる**ので限界費用が低い
- ただし**ツール側が未接続**で、公開方式が「下書きボックスへ送ってスマホで公開」（恒久仕様）、**24時間5件の上限**がある。手作業が1手増える
- **フォロワー数がリーチにほぼ影響しない**（3面で立ち上げ期のリターンが最も大きい）。見られているのは**完全視聴とループ**なので、冒頭1〜2秒で結論の断片を出し、尺を欲張らない
- **古い動画が数か月後に跳ねることがある。** IG・Xより資産性が高く、本数がそのまま在庫になる
- 若年層の検索が実際に来る（「誕生日 サプライズ」「記念日 プラン」）
- 手動公開の摩擦があるので、**開けても週1本まで**と決めて始める

### Meta広告（第2段）

- 即効性はここが一番。ただし**オーガニックで「何が刺さるか」を見つける前に金を出すと、何を増幅すればいいか分からないまま溶ける**
- **オーガニックで勝ちクリエイティブを選別 → その訴求で広告を作る**、の順番を守る
- ★ツール側の制約（`facts.md` 5-5）: **アプリから出したInstagram投稿をそのまま広告に回せない**（`source_instagram_media_id` が未対応）。**クリエイティブは画像のみ**で動画は選べない。つまり「当たったリールをブースト」は**現状ツールではできない**。詳細と回避策は9章

## 4. コンテンツ設計

### 差別化の芯をSNSに翻訳する

`メディア戦略.md` 2章の芯は「完全オーダーメイド＋専門知識による提案力」。SNSでは**提案そのものを実演する**のが最も伝わる。カタログを並べる競合と、そこで差が付く。

**実績の量・年数を暗示する表現は使わない**（`article-style-guide.md` 2章のルールをSNSにも適用）。「手がけてきた」「多数の実績」は禁止。語るのは**選び方の理由**と**組み立ての手つき**。

### フォーマット6種

軸は記事と同じ（軸1=gift / 軸2=date / 軸3=concierge）。**記事とネタ元を共有する**。

| # | フォーマット | 形式 | 軸 | 狙う行動 | 狙い |
|---|---|---|---|---|---|
| A | **ケース提案の実演** | カルーセル7〜10枚 | 1・2 | **送信＋保存** | 本命。「自分の場合は？」を起こす |
| B | **演出の実物** | リール15〜30秒 | 1・3 | **完視聴＋送信** | 新規リーチ。ビジュアルで止める |
| C | **逆算カレンダー** | カルーセル or リール | 1・2 | 保存 | 時期もの。後から見返される |
| D | **失敗回避（NG集）** | カルーセル5〜7枚 | 1・2 | **送信** | 「これ気をつけて」と送られる |
| E | **プランナーの視点** | リール or カルーセル | 全 | フォロー | E-E-A-T。人柄を出す |
| F | **記事の切り出し** | カルーセル | 記事に準拠 | 保存 | 制作コスト最小。記事公開に同期 |

**狙う行動は3章の「伸び方の違い」に対応させてある。** どの行動を取りにいく投稿なのかが決まっていないものは作らない。

**A（ケース提案）の型** — これを軸にする

```
1枚目: 条件だけ提示「彼女の誕生日／予算2万／付き合って1年／一人暮らし」
2枚目: プランナーならまず何を聞くか（＝ヒアリングの実演）
3〜4枚: 候補と、選んだ理由（なぜそれが喜ばれるのか）
5枚目: 渡し方・タイミング・言葉
6枚目: 店 or 当日の流れ
7枚目: まとめ＋「条件が違う人はプロフィールから相談」
```

1枚目は**条件だけを出して答えを出さない**。答えを見に2枚目へ送る作りにする。

**D（NG集）の型** — 「これはやめとけ」は保存される。ただし**断定の根拠を必ず添える**（style-guide 12章の専門知識でE-E-A-Tを担保する方針と同じ。「サプライズは予測できない嬉しさが満足度を上げる」のような一般知見 → 具体案、の順で書く）。

**Cの時期もの一覧**（逆算して仕込む。着火は本番の3〜4週前）

| 山 | 着火 |
|---|---|
| クリスマス | 11月中旬 |
| バレンタイン | 1月中旬 |
| ホワイトデー | 2月下旬 |
| 卒業・新生活 | 2月下旬 |
| 誕生日・交際記念日 | **通年**。ここが実は本体 |

**通年ネタ（誕生日・交際記念日）が地の収入源**で、季節の山は上乗せ。季節ものだけ追うと閑散期にアカウントが死ぬ。

### 素材の作り方（実績が少ない立ち上げ期）

- 実案件の投稿は**本人の許可が取れたものだけ**。かつ**日付をずらす**（サプライズのネタバレ防止）
- 許可が取れないうちは**自主制作で代替する**（バルーン・プレート・ラッピングを自分で組んで撮る）。「作ってみた」は嘘ではないので、実績の誇張に当たらない
- 撮影は**まとめ撮り**。月2回、1回で2週間分を撮ってメディアライブラリへ上げる

## 5. 運用フロー（ツールにどう乗せるか）

### 週次のサイクル

```
月曜 30分  : 先週の数字を /analytics で見る → 今週の3本を決める
月曜 90分  : 素材の準備（不足分だけ撮る／既存素材を組み替える）
月曜 60分  : コンポーザーで3本作成 → カレンダーに配置 → 予約
以降       : 予約が自動で出る。ストーリーズだけ随時（手動可）
```

**まとめて作って予約に流す**。毎日その日に考える運用は本業と両立しない。

### ★同じ投稿にXとIGを同時に入れない

**枚数・形式・サイズ・尺は、本文を上書きしても全配信先の交差が効く**（`facts.md`「投稿（コンポーザー / 制約）」）。XとIGを1つの投稿の配信先に並べると、**画像4枚・JPEG以外不可**まで縛られ、**カルーセル10枚が作れなくなる**。

→ **原則1投稿1プラットフォーム**。Xへの転用は「複製」から作り直す（複製時は `requestId` に複製元IDが混ざるので二重にはならない）。

### 投稿タイプごとの上限（コンポーザーが持っている表）

| 投稿タイプ | 本文 | 枚数 | 形式・尺 |
|---|---|---|---|
| X ポスト | 280 | 0〜4 | 画像 JPEG/PNG/WebP 5MB ／ 動画 MP4 512MB・140秒 |
| IG フィード | 2,200 | 1〜10 | **JPEG のみ** 8MB。2枚以上は自動でカルーセル |
| IG リール | 2,200 | 1 | MP4/MOV 100MB・**5〜90秒** |
| IG ストーリーズ | （無視される） | 1 | JPEG ／ MP4/MOV 60秒 |

**X の文字数はアプリのカウントとX実仕様がずれる**（コードポイント数で数えているが、Xは URL 23文字固定・CJK 2文字の重み付き）。**260文字程度で運用して境界に近づかない**。

### 事前に登録しておくもの（初回だけ）

- **ハッシュタグセット3つ**: `gift` / `date` / `surprise`。各セットに**ビッグ・ミドル・スモールを混ぜる**（スモールだけだと母数が無い、ビッグだけだと沈む）
- **定型文テンプレート**: CTA文（「条件が違う方はプロフィールのリンクから無料でご相談いただけます」）、免責文、価格の言い方（**定額メニューではない**ことを崩さない文言）
- **署名フッター**: IG用・X用でアカウント別に

### 投稿枠（初期仮説。数字が出たら4週で見直す）

| 曜日 | 枠 | 中身 |
|---|---|---|
| 月 20:00 | IG カルーセル | A or D |
| 木 20:00 | IG カルーセル | C or F |
| 金 21:00 | IG リール | B or E |
| 火・木・土 12:15 | X | リンク無し。コピーの実験 |
| 随時 | IG ストーリーズ | 週3〜5。手動でよい |

**cronの実行時刻は保証されない（数分遅れる）**ので、秒単位の時報ネタはやらない。

## 6. 導線設計

```
SNS投稿 → プロフィールのリンク（links.html） → LINE ／ 無料相談フォーム ／ LP ／ メディア
                                             ↑
                              ストーリーズのリンクスタンプ（手動運用）
```

- **本命は公式LINE**（`lin.ee/U4deTzi`）。12時間以内返信・相談無料・入金前キャンセル無料というLPの約束は、SNSからの温度が低い流入に対してこそ効く
- **`links.html` を必ず経由させる**（`noindex`・計測入り）。プロフィールからLPへ直リンクすると流入元が混ざる
- **ストーリーズのリンクスタンプはAPIで付ける公式手段が無い**（要確認だがツール側も未対応）。**リンク付きストーリーズだけは手動投稿**に倒す。ツールは画像・動画のストーリーズ配信までを担当する
- 記事との相互送客: 記事公開時にFフォーマットで切り出しを1本出す。記事側からSNSへは `follow_click`（実装済み）で拾う

### UTM（`計測設計.md` 7章の実施内容）

プロフィールに置くURLを差し替える。**着手前にこれを済ませる。**

- Instagram: `https://anniv.gift/links?utm_source=instagram&utm_medium=profile`
- X: `https://anniv.gift/links?utm_source=x&utm_medium=profile`
- ストーリーズから記事や相談へ直接飛ばす場合: `utm_medium=story` を使い、`utm_campaign` に投稿の識別子

**差し替えたら `計測設計.md` 7章の「未実施」を消す。**

## 7. 計測とKPI

### 3つの画面を混ぜない

| 画面 | 何を見る | 限界 |
|---|---|---|
| `anniv-tool.date/analytics` | **SNS側**。フォロワー推移・投稿別の相対比較 | **投稿から30日で観測停止**。以降はIGアプリで見る |
| GA4 | **サイト側**。links到達・LINEクリック・フォーム完了 | ブロッカーで欠損。傾向で見る |
| `anniv.gift/dashboard` | **事業側**。固定費とSNSの当月コスト | 金額だけ |

**接続点はUTMだけ**。ここが繋がっていないと「SNSは伸びているが売上に繋がっているか不明」になる（爆速開発部が詰まった状態そのもの）。

### 見る順番

1. **フォロワー推移**（`account_metrics` の日次）— 折れているか伸びているか
2. **投稿別の相対比較** — どのフォーマットが上位か。**絶対値ではなく順位で見る**
3. **GA4の `links_click` / `line_add_click`（label=`links`）** — 実際に人が動いたか
4. **`form_complete`（label=`contact_form`）** — 成果

### 面ごとに見る指標を変える（3章の伸び方に対応）

- **Instagram**: 保存と送信、次にプロフィールアクセス。**いいね数で判断しない**
- **X**: 投稿から1時間の反応だけ見る。**翌日の数字は見ない**（そこでは動かない）
- **TikTok**（開けたら）: 完全視聴率

取れるものが判明するまでは、**フォロワー推移と投稿別の順位だけで判断し、細かい指標はIG・Xのアプリ側で見る。**

## 9. 広告フェーズ

**開始条件: オーガニックで「中央値の3倍」を超えた訴求が3本たまったら。** それまでは出さない。

### 前提整備（この順番。承認待ちが長いので早めに出す）

1. Facebookページ作成 → Instagramアカウントと連携（**Instagram広告にFBページは必須**。`object_story_spec` に `page_id` が要る）
2. ビジネスマネージャで広告アカウント作成 → **支払い方法を登録**
3. Metaアプリに Marketing API プロダクトを追加（ビジネス認証は数営業日）
4. **本番に `META_APP_SECRET` を設定**（`wrangler secret put`）。**これが無いと接続画面まで進めない**
5. ツールの `/ads` から Facebook Login で接続 → 広告アカウント・ページ・IGアカウントを選択

### ★ツールの制約（回避策込み）

- **アプリから出したIG投稿をそのまま広告にできない**（`source_instagram_media_id` 未対応）。当たったリールをブーストする、が**できない**
- **クリエイティブは画像のみ**（動画はサムネイル指定が別途要るため塞いである）
- **既存投稿の流用は「Facebookページの投稿」から**のみ

→ **回避策は3つ。どれを採るかは実際に広告を出す段階で決める**

1. オーガニックで勝った**訴求（コピーと構図）**を、メディアライブラリの画像から**新規クリエイティブとして作り直す**（ツール内で完結。いま可能）
2. 動画広告をやるなら**広告マネージャで直接作る**（ツールの外。レポートはツールに乗らない）
3. ツール側に `source_instagram_media_id` 経路を足す（実装が要る。`facts.md` の持ち越しに記載済み）

### 最初のテスト設計

- 目的: `OUTCOME_LEADS`（着地＝LINE or `contact.html`）。**Pixelは導入済み**で `Lead` / `Contact` / `CompleteRegistration` が発火する
- 予算: **日1,000円 × 7日 = 7,000円**。クリエイティブ3本で回す
- ターゲット: 日本・20〜34歳・記念日/恋人系の興味関心。**EU/EEAはツールが塞いでいる**
- **すべて PAUSED で作られる。配信開始は独立した明示操作**（ツールの仕様。3階層をキャンペーン→広告セット→広告の順に有効化する）
- 停止は**広告だけ PAUSED にする**（親を止めると同じ広告セットの他の広告も巻き添え）。なお**親を止める操作がアプリに無い**ので、一覧は「配信中」と出続ける（実害は無い）

### 上限CPAの考え方

- 客単価の目安は2〜5万円。**相談は無料**なので、まず見るのは「無料相談1件あたりの獲得単価」
- **相談→受注率が未知**なので、初回は **1件3,000円を仮の上限**に置く。7,000円で2件取れれば合格、0件なら訴求かターゲットのどちらかが外れている
- 受注が数件たまったら、受注率から逆算して置き直す

## 10. TikTokを開ける条件

**次の3つが揃ったら**（ツール側 `1-4` / `3-X` の `deferred` を開ける）:

1. IGリールを**月4本以上、3か月継続**して出せている（＝縦動画の制作が回っている）
2. IGとXの投稿が**本番で1か月以上、事故なく**回っている（ツール側の着手条件そのもの）
3. リールの指標が伸びていて、**同じ素材を流すだけで追加リーチが見込める**と判断できる

**開けるときの前提**: 公開は「下書きボックスへ送信 → スマホで公開」（恒久仕様）。**24時間5件**が実質の上限。審査（2〜4週間）に通れば `posting_mode` を `direct` に UPDATE するだけで直接公開に切り替わる（コード変更不要）。

## 11. 運用上の落とし穴

**ツール固有。踏むと止まるので着手前に読む。**

- **Instagramドライバは実APIを1度も通していない**（モックのみ）。**最初の1本は「ドライラン → 今すぐ投稿」で、画像1枚のフィード投稿から試す**。コンテナ作成のリクエスト形式が不確実で、`code:100` で落ちる可能性が既知
- **R2の公開ドメインが `.date`（新gTLD）で、Metaが弾くかは未検証**。弾かれたら `R2_PUBLIC_BASE_URL` の1か所を別TLDに移す
- **IGのpermalinkをアプリが保存しない**。投稿後にアプリからその投稿へ飛べない。**URLは自分で控える**
- **Instagramは24時間で100件の上限**。Metaはレート制限を**HTTP 400で返す**
- **トークン**: IGは60日で失効（cronが50日目に更新）、Xはワンタイム更新。`expired` になったら通知が出るので**再接続する**
- **`external_post_id` が付いた投稿はアプリから削除できない**（外部に出た証拠があるものは消さない設計）。消すならSNS側で消す
- **予約時刻は「その時刻以降の最初のcron実行」**。数分の遅れがある
- **分析は投稿から30日で停止**。長く伸び続けるリールは30日以降IGアプリ側で見る
