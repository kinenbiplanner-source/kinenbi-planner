## Git 運用のメモ

`master` が本流でリモートのデフォルトブランチ（2026-08-26 に `main` から変更。`main` はGitHubのWeb UIから `index.html` を1つアップしたときにできた履歴の繋がらない孤立ブランチだったので削除した）。

push は Git Credential Manager がGUI認証を出すので、**手元のターミナルで実行する必要がある**（自動実行では認証待ちで止まる）。

作業ブランチを master へ寄せるときは、**checkout せずにリモート側を進める**のが安全（別セッションの未コミット変更があると `git checkout master` が弾かれるため）：

```bash
git push origin feat/astro-media:master
```

### 本番への反映は push では起きない

**push しても本番は変わらない。** Cloudflare Workers Builds をリポジトリに繋いでいないので、
デプロイは wrangler から手で叩く（GitHub側にビルドのチェックも Deployments も出ないのはこのため。
最後の GitHub Deployments は 2026-08-26 の Vercel のもので、以降は増えていない）。

```bash
npm run deploy
```

中身は `astro build && wrangler deploy`。wrangler は OAuth のトークンがマシンに入っていれば
そのまま通る（`npx wrangler whoami` で確認できる）。完了すると `anniv.gift` の custom domain に即反映される。

- **記事の見た目（`src/lib/markdown.ts`）を変えたときは、デプロイ後に `/admin` の「全記事を再レンダリング」も押す。**
  `body_html` は保存時に作ってD1に入っているので、デプロイだけでは既存記事のHTMLが古いまま
- 反映確認は PowerShell なら `curl` ではなく `curl.exe`（`curl` は `Invoke-WebRequest` のエイリアスで、
  `-s -o -w` を解釈できない）：

```powershell
curl.exe -s https://anniv.gift/media/<slug> | Select-String "cta-box-inner"
```

## 改良（効果が大きい順）

### A. アイキャッチ画像の運用を決める
R2アップロードは実装済み。**一覧のCTRに直接効く**ので記事が数本たまる前にやる。

> 繋ぎとして、アイキャッチ未設定のカードは**軸で地の色・記事idでグラデーションの角度**を変えるようにした（`media.css` の `.card-thumb.is-empty.is-*`）。全カードが同じ絵になる問題は消えたが、**実画像の代わりにはならない**。テンプレが決まったらこのCSSは消せる。

**残っている作業**：下のプロンプトで軸別に3枚のベース画像を作る → 1本の記事で試す → 良ければ `素材/ブランド/` に置いて運用開始（`記事背景.png` が先行の別案としてそこにある）（＋上記CSSを消す）。

#### 決めたこと（テンプレ）

- **1200×675（16:9）**。カードは `object-fit: cover` の16:9、かつ**記事のOGP画像を兼ねる**（`MediaArticle.astro` の `ogImage={heroPath}`）。X等で 1.91:1 に切られるので**上下左右4%はセーフマージン**として何も置かない
- **ベース1枚＋記事ごとの差分**という作り。差分は**右のアーチの中のイラスト1点**だけに集約し、左のテキストとアーチの位置は動かさない（動かすと一覧がバラつく）
- **テキストは左55%に2行まで**。1200px基準で**60px以上**（カードは実寸360px前後まで縮むので、これ以下だと一覧で潰れる）
- **焼き込む文字は記事タイトルの丸写しにしない**。カードの下にHTMLでタイトルが出るので重複する。入れるなら「予算1万円台」「個室の取り方」のような**短いフック語だけ**（A-2 の「文字は焼き込まない」と同じ理由で、長い文言を焼くと直すたびに作り直しになる）
- 書き出しは PNG → `node .claude/scripts/card-renderer/to_webp.mjs <png>` で WebP。アップロードは記事エディタの「ヒーロー画像」欄
