## 実際に使っている背景はここではない

Instagram のカルーセルが敷く背景は **`.claude/scripts/ig-renderer/bg/light.png` と `dark.png`**。
レンダラー（`render.mjs`）がそのパスを直接読むので、**差し替えるならあちらを置き換える**。
ここのファイルを変えても投稿画像は変わらない。

以前 `インスタ/背景2.png` `背景3.png` があったが、上の2枚と中身が完全に同じ（ハッシュ一致）だったので消した。
