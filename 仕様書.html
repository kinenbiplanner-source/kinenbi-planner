1. サービス概要

パートナーがいる男性ユーザーに向けて、記念日・誕生日などの特別な日の準備をトータルサポートするサービス。プレゼントの選定・手配・配送から、レストラン予約、演出シナリオの提供まで、当日のストーリー全体をプロデュースする。

ターゲットユーザー

項目内容
性別・関係性パートナーがいる男性
年齢層大学生〜20代社会人
特徴記念日に何かしたいが何をすればいいかわからない、手間をかけたくないが気持ちは伝えたい層

2. 料金（見積もり制）

固定プランは設けず、ヒアリング後にプランナーが個別見積もりを提示する見積もり制で運用する。LP上は「予算の目安」としてレンジを提示するのみ。

ご予算の目安（LPに掲載）

予算帯サービス例
〜20,000円プレゼント＋演出指示書
〜35,000円プレゼント＋レストラン予約＋演出指示書（よく選ばれる予算帯）
〜50,000円上記＋特注アイテム・旅行プランニング等
50,000円〜完全オーダーメイド（要相談）

料金算出のルール

  • プレゼント代＋サービス料＋手配費（必要に応じて）の合算で算出
  • 顧客のヒアリング内容（パートナーの好み・予算感・希望サービス）を踏まえてプランナーが最適な内容と見積もり額を提示
  • 顧客の承認後に Stripe Invoice で請求書を発行し、LINEでURLを送付

特急オプション

通常申し込み特急申し込み特急追加料金
記念日の1週間前まで記念日の2日前まで+3,000〜5,000円程度（見積もりに含めて提示）

3. ユーザーフロー（カスタマージャーニー）

顧客対応は LINE公式アカウント 中心。メールは受付確認のみ。入口では3つしか聞かず、詳しいアンケートは友だち追加のあとに回す（設問が多いと答え切る前に離脱するため）。

6. メール・通知フロー

タイミング送信者内容
申込フォーム（/apply）送信直後システム（Worker → Resend）顧客へ受付確認メール。受付番号・LINE友だち追加の案内・アンケート（/survey）のリンク
申込フォーム送信直後システム（Worker）運営者へ新規受付の通知（メール＋LINE push）
LINE友だち追加の直後システム（LINE Messaging API の Webhook）顧客へ「アンケートにご協力ください」＋ /survey のURLを自動送信。あわせて申し込みとの紐づけ候補を運営者へ通知
アンケート回答直後システム（Worker）案件に回答を反映（survey_at が立つ）＋運営者へ通知
受付から12時間以内運営者（人力）LINEで初回連絡。以降のヒアリング・プラン提案・決済案内・納品もLINE上で行う
メール送信に失敗しても受付自体は失敗させない（案件は先に D1 に入り、履歴に失敗が残る）。通知が来なかった日は /admin/cases を直接見る。

9. HP・システム要件（MVP）

技術スタック（確定）

用途ツール選定理由
ホスティング・LP制作 HTML/CSS + Astro 7 + Cloudflare Workers（@astrojs/cloudflare） 確定 本番は https://anniv.gift。public/ の素のHTMLはそのまま配信し、/media・/admin・/api は Worker がその場でレンダリングする。固定費0円。2026-08 に Vercel から移行
ソース管理 GitHub 確定 kinenbiplanner-source/kinenbi-planner。本番反映は npm run deploy を手で叩く（Workers Builds は繋いでいないので push では変わらない）
申込フォーム 自前（/apply） 確定 お名前・メールアドレス・LINEのお名前の3つだけ。2026-09-07 に15問から絞った（長いと答え切る前に離脱するため）。同一サイト内なので計測が分断されない
詳しいアンケート 自前（/survey） 確定 記念日の種類・日付・予算が必須。パートナーの好みなどは任意。LINE で友だち追加したあとに自動で案内が飛ぶ
無料相談の窓口 自前（/contact） 確定 軽い相談用。送信先は申込と同じ API（kind=consult として同じテーブルに入る）
顧客・案件管理（データ） Cloudflare D1（anniv の cases テーブル） 確定 旧 Notion の「顧客管理DB」「案件管理DB」を1テーブルに畳んだもの。生の回答は submission_json に持つので、設問を増やしても過去の行が壊れない
案件管理画面 自前（/admin/cases・/admin/cases/<id>・/admin/cases/insights） 確定 一覧・詳細・回答の集計。リクエストのたびに Worker が D1 を読んで描くので転記が要らない。Cloudflare Access で保護
受付確認メール Resend（Worker から直接送信） 確定 申込直後に受付番号・LINE追加案内・アンケートのリンクを送る。運営者への通知も同時。無料枠は月3,000通・1日100通
顧客とのコミュニケーション LINE公式アカウント（Messaging API） 確定 申し込み後の追加ヒアリング・プラン提案・決済案内・納品・フォローまで全てLINE上で行う。無料プラン（フリープラン）で運用。Webhook で友だち追加を検知して案件と紐づける
決済（クレカ・メイン） Stripe（Invoicing機能） 確定 案件ごとに見積もり額で請求書（Invoice）を発行 → URLをLINEで送付 → 顧客が支払い。プラン固定リンクは作らない
決済（PayPay・補助） PayPay for Business PayPay派の顧客向け補助手段として提供
画像の保管 Cloudflare R2（anniv-media） 確定 記事・LPで使う画像の置き場。/media/img/<key> で配信する
bot対策 Cloudflare Turnstile 確定 /apply に設置。あわせて同一IP 10分5回のレート制限とハニーポットも掛ける
管理画面の認証 Cloudflare Access 確定 /admin 配下をパスポリシーで保護。workers.dev のサブドメインは無効化して迂回経路を塞いでいる
事業所所在地 GMOバーチャルオフィス（大阪・梅田） 確定 月660円。特商法ページの所在地表示用。自宅住所の公開を回避
銀行口座 PayPay銀行 確定 Stripe・PayPay for Business の振込先口座
2026-08〜09 に廃止したツール：Tally / Make / Notion / Typeform / Zapier / Framer / Vercel / formsubmit.co。受注フローの実装・設定手順の詳細は 受注フロー.md が正。

テスト工程確認内容
