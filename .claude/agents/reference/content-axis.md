# コンテンツ軸定義（SSOT）

Annivメディアの記事制作で、**テーマ領域＝「コンテンツ軸」ごとに切り替わる設定**を集約する。`anniv-write-article` の Step0 で軸を選び、competitor-researcher（リサーチ観点）と article-writer / article-reviewer（文体の寄せ）に引き継ぐ。

> 爆速開発部メディアの同名ファイルをベースにAnniv（記念日のプレゼント選び・レストラン予約・サプライズ演出をトータルサポートするサービス）向けに書き換えたもの。共通ルール本体（骨格・SEO・装飾・チェックリスト等）はそのまま流用できる設計思想を維持している。

## 役割分担（重要）

- **共通ルール本体**＝`article-style-guide.md`（SSOT）。骨格・H2数・SEO見出し・装飾・自己言及禁止・まとめH2・タイトル・チェックリストなど、**全軸で不変**のルール。軸では上書きしない。
- **メディアの声（トーン）も全軸共通**＝style-guide 8-0章。「記念日のプランを一緒に考えている人」が友人の相談に答える声で、親しみやすく寄り添いつつ事実は言い切る。**軸で変わるのは「何に寄り添うか」と「どこを断定するか」の配分だけ**で、声そのものは変えない（軸2・軸3だからといって事務的・レポート調にしない）。
- **このファイル**＝軸ごとに変わる「リサーチ観点／文体の寄せ／想定読者／ファネル層／収益CV」だけを定義。style-guide と矛盾する指定はしない（**衝突時は style-guide が優先**）。
- **記事ごとの読者レベル・深度**＝検索意図から判断（style-guide 1章）。

## 2つの分類は直交する

記事1本は「**コンテンツ軸（テーマ）× ファネル層**」で位置づける。

- **コンテンツ軸（テーマ）**：文体・リサーチ観点・収益CVを切り替える単位。＝下記「軸一覧」
- **ファネル層**：サイト上の役割。**集客 / 比較・検討 / 課題解決** の3つ。"受け皿"（フォーム）はCV着地点であって記事カテゴリではないので含めない。

frontmatter は `axis`（軸）と `funnel`（ファネル層）を両方持つ。KWマスターDB も「軸」列＋「ファネル層」列で管理する。テーマ（軸）・検索意図（記事単位）・ファネル層（サイト分類）の三者は独立。

> **どの軸もファネル3層すべてを取りうる**（2026-08-26 更新）。当初は軸ごとに取りうる層を絞っていたが、59KWのSERP実地調査の結果、**最も勝ち目のあるロングテールがその制約の外にあった**。具体的には軸1×課題解決（「彼女 プレゼント いらないと言われた」「サプライズ ばれた 気づかれた 対処」など）で、大手ECもギフトメディアも拾っていない空白地帯だった。制約は当初の見立てにすぎず、実データが優先する。ただし**軸ごとの「取りうる層」は依然として重心の目安**なので、下記の各軸の記述順（先に書かれている層ほど中心）は参考にする。

## 軸一覧

### 軸1：記念日ギフト・サプライズ

- **テーマ範囲**：プレゼント選び方（交際期間・年代・記念日の種類別）、サプライズ演出のアイデア・進め方、失敗しないギフト選定の考え方
- **想定読者**：**恋人・交際中カップルが中心**。恋人の誕生日・記念日・付き合った記念日などを控え、何を贈るか／どう演出するかで迷っている人（Annivのメインターゲット。LPの想定と一致）
- **リサーチ観点**（researcherへ）：プレゼントの相場感（予算帯別）・交際期間/年代別の人気傾向・ありがちな失敗パターン・サプライズ演出の具体アイデア事例・渡すタイミングやシチュエーションの工夫
- **文体の寄せ**（writer/reviewerへ）：**寄り添いの比重が最も高い軸**。読者は「相手に喜んでほしいのに正解が分からない」状態なので、迷いを言語化して受け止めてから判断材料を出す（style-guide 8-0・8-2章）。その上で事実ベース＋実体験寄り（style-guide 8章を厳守・上書きなし）。プレゼント選定・演出を実際にプロデュースしてきた具体エピソードは歓迎（社名は伏せてOK）。**心理学・マナーなど「なぜそれが喜ばれるか」を説明できる専門知識の裏付けを積極的に使う**（実績の量で語れない分、E-E-A-Tはここで担保する。下記「E-E-A-Tの担保方法」参照）
- **取りうるファネル層**：集客 ／ 比較・検討 ／ 課題解決
- **収益層・CV**：Anniv送客（無料相談）

### 軸2：記念日デート・レストラン

- **テーマ範囲**：記念日ディナーの店選び（個室・夜景・雰囲気などの条件整理）、エリア別の選び方、予約のコツ・当日の伝え方（サプライズ演出をお店に頼む場合の段取りなど）
- **想定読者**：**恋人・交際中カップルが中心**。記念日のレストラン・お店を探している人、当日の過ごし方・段取りに悩む人
- **リサーチ観点**：エリア/シーン別のお店選定条件（個室・夜景・記念日プラン有無）・予約の取り方や早さの目安・当日サプライズを店側に依頼する際の注意点・費用感
- **文体の寄せ**：比較・検討寄り。判断軸を明快に・結論ファースト・条件を表で整理する（style-guide 8章の範囲内）。**ただし店選び・予約の話は事務的になりやすい**ので、条件の羅列で終わらせない。「なぜその条件が記念日に効くのか」「当日どう過ごすことになるのか」を一言添えて、段取りの話を体験の話に戻す（8-2章の型4）
- **取りうるファネル層**：集客 ／ 比較・検討 ／ 課題解決
- **収益層・CV**：Anniv送客（無料相談）

### 軸3：記念日代行・サプライズ代行サービス

- **テーマ範囲**：「記念日の準備を丸ごと誰かに頼みたい」層向け。代行サービスの選び方・比較軸、プレゼント代行/サプライズ演出代行の仕組みや相場、自分で準備する場合との比較
- **想定読者**：**恋人・交際中カップルが中心**。仕事や距離の事情で自分では準備しきれない、センスに自信がない、失敗したくない――で「代行」を検討している発注検討者
- **リサーチ観点**：代行・プロデュースサービスの相場帯・提供範囲（プレゼントのみ／レストランのみ／トータル）・**「プラン固定型」か「都度カスタムのオーダーメイド型」かの提供形態**・依頼から当日までの流れ・失敗しないサービスの見極め方
- **文体の寄せ**：事実ベース＋**意思決定支援**（判断軸を明快に・結論ファースト・料金は具体的な幅で示す）。**「人に頼むこと自体への後ろめたさ」に寄り添う**のがこの軸の温度：自分で準備できないことを責めず、頼む選択を普通のこととして扱う（「忙しくて準備の時間が取れないまま当日が近づくことはよくあります」）。営業トーンに寄せない。**Annivらしさ＝「完全オーダーメイド」**：型にはまったプラン紹介で終わらせず、「関係性・予算・希望に応じて都度カスタムする」という提供形態そのものを判断軸として提示する（2章「差別化の芯」参照）
- **自己言及・看板ワードOK（この軸だけの例外／style-guide 2章）**：作り手＝Anniv側の立場を「信頼の裏付け」として出してよい（例「実際に依頼を受ける中で」「Annivが相談を受けていて」）。ただし乱用・自賛・煽り（8章）はNG、比較記事では中立を保つ（他社比較で自社だけ持ち上げない）。**実績はまだ少ないため、「手がけてきた」「多数の実績」など実績の量・年数を暗示する表現は使わない**（style-guide 2章）
- **取りうるファネル層**：比較・検討 ／ 課題解決
- **収益層・CV**：Anniv送客（無料相談・お問い合わせ）
- **Anniv送客CTAブロック（固定CTA・この軸の記事に必須）**：この軸の記事には、無料相談への固定CTAブロックを1つ入れる。挿入は anniv-write-article Step6（orchestrator担当。writerではなくorchestratorが入れる）。他軸の記事には入れない。
  - **挿入位置**：代行を検討する気持ちが最も濃くなるセクション（料金・依頼の流れ・サービスの選び方など）の直後。該当が薄い記事はまとめH2の直前。**1記事に1つだけ**（乱発しない）。
  - **固定（改変しない）**：`label="無料相談・お問い合わせ"`、フォームURL `https://anniv.gift/contact`。
    - **`label` が CTA の判定キー**：`src/lib/markdown.ts` はこの label を見て `.cta-box`（ゴールド）として描画し、**`color` 指定は無視する**。だから雛形に `color` は書かない（書いても効かないので、書くと実装とズレた記述が残る）
  - **可変（記事テーマに寄せてよい）**：リード1文だけ。効能保証・煽りはNG（style-guide 8章）。「予算や希望が固まっていない段階の相談も受け付けている」旨は発注者の丸投げ不安に効くので原則残す。
  - **雛形（このまま貼る）**：
    ```
    :::box label="無料相談・お問い合わせ"
    記念日の準備をまるごと任せたいなら、[お問い合わせフォーム](https://anniv.gift/contact)から無料でご相談いただけます。予算や希望が固まっていない段階のご相談も受け付けています。
    :::
    ```

## 新しい軸を足すとき

1. 上の軸ブロックを1つ複製し、6項目（テーマ範囲／想定読者／リサーチ観点／文体の寄せ／ファネル層／収益CV）を埋める
2. `anniv-write-article` Step0 の軸選択肢にその軸名を1つ足す

これだけで新軸が制作フローに乗る。共通ルール（style-guide）は触らない。
