# 記事品質 改善ループ（試験運用・共通仕様）

`/write-article`（Step 5）と `/rewrite-article`（Step 2）が共通で使う「レビュー→再執筆」の自動改善ループの仕様。**ここが唯一の正本（SSOT）**。両オーケストレーターと article-writer はこのファイルを参照する（ルールをコピペしない）。

---

## 有効/無効と切り替え方法

**現在のステータス：有効**

このループは試験運用中。**無効化したくなったら、この行を「無効」に変えるだけでよい**（参照元は「無効なら通常フロー」と解釈する）。完全に撤去する場合は、このファイルを削除し、各参照元の「改善ループ（試験運用）」節を消す：

- `.claude/skills/write-article/SKILL.md`
- `.claude/skills/rewrite-article/SKILL.md`
- `.claude/agents/article-writer.md`

無効化すると Step 5（レビュー）は1回で完了し、そのまま保存ステップへ進む（writer↔reviewer の再ループはしない）。

---

## 発動条件

article-reviewer が返す総評スコアが **85点未満** のとき発動する。85点以上なら即抜けてループしない。

## ループ手順

1. reviewer が指摘した Must Fix・気になる点・改善例を整理する
2. **article-writer を「改善ループモード」で再起動**し、以下を渡す：
   - 直前の記事本文（初回はレビュー1回目の修正版）
   - レビュー指摘内容（Must Fix・気になる点・改善例）
   - 「指摘内容を反映して全文を修正してほしい」という指示
   - ユーザーメモ（あれば）
3. 返ってきた修正版を **article-reviewer で再レビュー**
4. スコアが **85点以上** になれば抜ける
5. **最大3ループまで**（無限ループ防止）。3ループ目でも85未満なら、その時点の最終版を採用し、ユーザーに「85点未達のまま3ループ完了」と報告する

## article-writer 側の振る舞い（改善ループモード）

writer は上記手順2で再起動されたとき、新規執筆ではなく**直前の本文をベースに指摘箇所だけを修正した最終版**を返す。文体・構成は維持し、修正が必要な箇所のみ手を入れる。

## article-reviewer 側の振る舞い（改善ループモード・2周目以降の軽量レビュー）

**軽量レビュー：有効**（重くしたい時はこの行を「無効」に変える＝毎ループ初回と同じフルレビューに戻す）

ループ2周目以降（＝1回はフルレビュー済みの再レビュー）は、reviewer はフルチェックリストを頭から回さず**差分レビュー**でよい：

1. 前ループで出した Must Fix・気になる点が**解消されているか**を1件ずつ確認
2. 修正で新たに崩れた箇所がないかの**回帰チェック**（修正部の前後の骨格・文体・自己言及・往復）
3. **事実確認パス（5-A）は今回writerが新規追加/変更した数値だけ**に絞る（前ループで確認済みの数値は再検索しない）
4. 18章チェックリスト全項目の再走査は**初回レビューのみ**。再レビューは上記1〜3＋スコア再採点で足りる

これで2周目以降のWeb検索とトークンを抑える。**初回（ループ前の1回目）のレビューは従来どおりフル**（5-A〜5-E＋18章）。この軽量レビューを「無効」にすると毎ループ全項目のフルレビューに戻る。

## スコア推移の表示

各ループのスコア推移（例：72→81→87）は、オーケストレーターが最終出力時に表示する：

- `/write-article` … Step 6
- `/rewrite-article` … Step 3
