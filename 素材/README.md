# 素材（この1か所だけ）

Anniv の画像素材はぜんぶここに置く。**2026-09-13 に `広告素材/`・`ブランド素材/`・`.claude/scripts/ig-renderer/bg/` を畳んで集約した。** 用途ごとに3つのサブフォルダに分ける。混ぜない。

| フォルダ | 何を置くか | 誰が読むか |
|---|---|---|
| `写真/` | 記事本文・IG の表紙に差し込む **CC0 の写真**（62枚）。一覧は `写真/一覧.md` | `/anniv-write-article` Step 6（記事）／`ig-renderer`（表紙の円セル） |
| `ブランド/` | **ロゴ・背景の原本**。IG カルーセルの背景 `ig-light.png` `ig-dark.png`、背景の候補、記事アイキャッチ用の `記事背景.png` | `ig-renderer/render.mjs` が `ig-*.png` を直接読む。他は原本（未使用） |
| `広告/` | Meta 広告のバナー（`anniv-ad-01-*.png`）と、それを作った `specs/*.json` | `.claude/scripts/ad-renderer/render.py`（spec の `output` はリポジトリルート相対。ルートから叩く） |

**`public/assets/` は素材置き場ではない。** あそこは本番で配信するファイル（ロゴ・OGP・LP の写真・CTA 画像・著者アイコン）。素材を公開面で使うときは R2（記事）か `public/assets/`（LP・レイアウト）にコピーする。URL が変わるので `public/assets/` の中は動かさない。

## 写真（`写真/`）

- **すべて CC0**。商用可・クレジット不要。取得元と権利の注意は `写真/一覧.md`（ファイル名・サイズ・元ページの表）
- 記事で使うときは管理画面の「画像をアップロード」で **R2 に上げて** `![alt](/media/img/<key>)` で参照する。ローカルパスのままだと公開先で壊れる（公開前チェックが×で拾う）
- IG の表紙で使うときは spec.json に `"photo": "素材/写真/<file>.webp"`（リポジトリルート相対。`render.mjs` が解決する）
- **足すときの条件**：CC0 かつ 顔が特定できない（`一覧.md` の「権利まわりの注意」）。撮った実物写真はここではなく `記事管理/SNS原稿/実例/`（`投稿台本.md`）

## ブランド（`ブランド/`）

紺（`#1a2840` 系）×金のブランド背景。**すべて右下にロゴが焼き込まれている**ので、テンプレ側でロゴを重ねない。

| ファイル | 中身 | 使われ方 |
|---|---|---|
| `ロゴ.png` | リボン付きの円＋ANNIV（紺×金・小） | 原本。配信用は `public/assets/logo.png` `logo_trans.png` `anniv_logo_symbol_square.png` |
| **`ig-light.png`** | アイボリー地。左下に紺の大きな曲面、上に金の弧が2本、右上に薄い青のグラデ。ロゴは紺 | **IG カルーセルの本文スライド（既定）。** `render.mjs` が読む。文字の安全域は y900 まで |
| **`ig-dark.png`** | 紺地（中央がわずかに明るい）。四隅から金の細い曲線と粒子。ロゴは白線＋金リボン | **IG の表紙と締め、長い本文（`"bg":"dark"`）。** `render.mjs` が読む |
| `背景1.png` | アイボリー地。金の細い曲線と薄い帯が左上・右下に大きく流れる。ロゴは紺 | IG light の別案（旧 `ブランド素材/背景_未使用1.png`）。未使用 |

| `背景6.png` | アイボリー地。左下に紺の波、それに沿う金の弧と粒子。ロゴは紺 | 候補（同）。`ig-light` に近い構図。未使用 |
| `背景7.png` | 紺地。左右から金の曲線と粒子。ロゴは白 | IG dark の別案（同）。未使用 |

- **IG の背景を差し替えるときは `ig-light.png` / `ig-dark.png` を上書きする**（`render.mjs` はこのファイル名を固定で読む。`背景N.png` を編集しても投稿画像は変わらない）
- サイズは IG 用が 1080×1350（4:5）。`記事背景.png` だけ 16:9

## 広告（`広告/`）

- `anniv-ad-01-{feed,square,story,reel}.png` … Meta 広告の1本目（2026-09-02）。サイズ違いの4枚
- `specs/ad-01-*.json` … 上を出したときの原稿。作り直すときは `python .claude/scripts/ad-renderer/render.py 素材/広告/specs/ad-01-feed.json`（リポジトリルートから）。`output` は `素材/広告/…` のルート相対
- 広告の方針・運用は `メディア方針/SNS戦略.md`

## 触るときのルール

- 参照しているのは `CLAUDE.md`・`.claude/skills/anniv-write-article/SKILL.md`・`article-style-guide.md` 9章・`投稿台本.md`・`改良ロードマップ.md` A／A-2・`ig-renderer/render.mjs`・`記事管理/SNS原稿/*/spec.json`。**フォルダ名やファイル名を変えたら、これらも直す**（2026-09-13 の集約でも同じ手順で直した）
- 新しい種類の素材（動画・音源など）が増えたら、ここにサブフォルダを足して上の表に1行足す。リポジトリ直下に新しい「◯◯素材」フォルダを作らない
