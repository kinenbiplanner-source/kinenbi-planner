# 記事用の素材画像（フリー素材ライブラリ）

Annivメディアの記事本文に差し込むための写真素材。**すべて CC0（パブリックドメイン相当）**で、商用利用可・クレジット表記不要のものだけを集めている。取得元は [Openverse](https://openverse.org/) の CC0 フィルタ経由で、提供元は rawpixel と StockSnap。

## 使うときのルール

- **公開時はR2へアップロードする**：`/admin/new` の「画像をアップロード」ボタンでこのフォルダのファイルを上げ、挿入された `![alt](/media/img/<key>)` を使う。ローカルパスのままだと公開先で壊れる（公開前チェックが×で拾う）
- **altは必ず書く**（style-guide 9章）。メインKWか関連語を自然に含め、写真の内容を客観的に説明する
- **写真はイメージ**。料金・比較・手順など情報そのものは表・箇条書き・要約カードで見せる。写真で情報の代わりをしない
- 同じ写真を複数記事で使い回すのは可。ただし**同じ記事内で2回使わない**
- サイズは幅 **960〜1024px**（本文カラム760pxに対しては十分）。**ヒーロー画像に使うと少し眠い**ので、ヒーローは別途大きい素材を用意する
- WebP・品質80で保存済み。1枚10〜150KB、全62枚で約3MB

## 権利まわりの注意

- ライセンスはすべて **CC0 1.0（またはPublic Domain Mark）**。クレジット表記は不要だが、出所を追えるように下の表に取得元ページを残してある
- **CC0は著作権の話で、肖像権・商標は別**。人物が写っているものは顔が写り込まないカット（手元・後ろ姿・シルエット）だけを選んでいる
- ブランドロゴ・商品パッケージが目立つものも外している
- **素材を足すときも「CC0」かつ「顔が特定できない」の2条件を守る**。取得は Openverse API（`license=cc0`）で、提供元は rawpixel / StockSnap を優先すると質が揃う
